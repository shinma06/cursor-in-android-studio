# 2026-09-06 入力エリアのCursor外観・操作改善（#27 / #19）

ユーザーが提示した6枚のCursor画面を参照し、入力エリアを改修。画像は参照証跡であり、プラグインの合格証跡とはしない。

## 実装

- モデルボタンを自然幅にし、残りの余白をクリック領域から外した。狭い幅ではモデル表示のみを省略、完全名とIDをtooltipに表示。
- 検索欄、現在モデルのチェック、Autoトグルを持つモデルpopup。名前・IDを大文字小文字を区別せず検索。候補はCLI取得結果。
- Autoオンで個別モデル一覧を畳み説明を表示。オフで直前の個別モデルへ戻す（同じselectorインスタンス内。起動時Autoで以前の個別モデルが不明なら先頭候補）。検索/候補移動だけでは設定を変更せず、Escapeで閉じる。Autoトグル/候補確定は即反映。
- Agent/Plan/Askをアイコン＋チェック付きメニューにし、Planは橙、Askは緑のpill。
- 入力は実エディタの折り返しを含む表示行数で伸長、上限12表示行で縦スクロール、削除で縮小。macOSのoverlay設定に依存しない細いスクロールthumbを追加。
- placeholderは指定どおり `Plan, Build, / for skills, @ for context`。送信中Enterの再送信を抑止。
- Debug/MultitaskのCLI対応調査（#25）、モデル管理、skill実行はこの外観改修で追加していない。
