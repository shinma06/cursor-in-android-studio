# STOP-UX-1 — 意図した停止をエラーにしない

Issue #46のStopped/Error区別に限定した部分実装。経過時間、ツール詳細、一般の通知整理は残る。
停止アイコン自体はPR #70の範囲であり、この変更は終了理由を扱う。

## 受入と実装

停止要求を応答ごとのAgentRunに記録し、終了コード137だけから停止を推定しない。
停止した応答は「停止しました」と表示し、エラー行・エラーダイアログ・完了/エラー通知を出さない。
途中の応答本文は保持する。準備中は即座に入力へ復帰し、遅れて作られたプロセスも破棄する。
プロセス実行中は終了コールバック後に入力へ復帰する。既に終了が観測されたプロセスへの
遅い停止操作は実際の終了理由を上書きしない。停止前に検出した失敗やOSによる強制終了は
停止要求なしなら異常として扱う。新規会話/履歴移動/次の送信後に旧応答のUIを更新しない。
