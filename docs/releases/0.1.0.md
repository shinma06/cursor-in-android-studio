# 0.1.0 — Platform 261モダン化の正式公開

2026-09-22 / [Phase 6 #393](https://github.com/shinma06/cursor-in-android-studio/issues/393)。mainの既存機能を維持した単一JVM21 ZIPを正式公開した。develop未反映のACP・本文保存・Tab/@等の変更は含まない。

## 取得とインストール

[インストール用ZIP](https://github.com/shinma06/cursor-in-android-studio/releases/download/v0.1.0/cursor-in-android-studio-0.1.0.zip)をダウンロードし、Settings → Plugins → ⚙ → Install Plugin from Disk... で選択、再起動する。認証済みのCursor `agent` CLIが必要。Terminalプラグインは任意で、無効でもチャットを利用できる。Plugin ID `com.cursoragent.plugin` と設定・履歴の保存先は維持した。

[Release](https://github.com/shinma06/cursor-in-android-studio/releases/tag/v0.1.0)のSource code (zip)はインストール用ではない。manifest・inputs・bundle・両compatibility ZIPは検証資料。Release本文は不変性照合用の機械記録なので、公開後に本文やassetsを書き換えない。

Gradle実行はJDK21、公開inputsの実測は21.0.11。本体171クラスはmajor65/JVM21。IDE JBR25対応のためのbytecode25化・JVM別ZIP/source set・runtime分岐は追加していない。KGP2.4.20の公式完全サポート上限はGradle9.7.0で、採用9.7.1を公式範囲内とは表記しない。今回のbuild/test/Verifier/GUI成功が実測根拠である。[Kotlin互換表](https://kotlinlang.org/docs/gradle-configure-project.html)。

`androidStudio("2026.1.1.8")` の標準解決をlocal/CI/branch ZIPで共用する。local SDKは `-PuseLocalPlatform=true -PplatformPath=...` の明示時だけ使え、実full buildの不一致・確認不能は失敗する。旧URL問題を理由に標準取得を無効にしない。

公開ZIPのlibは本体・searchableOptionsの2 JAR、`gson-2.14.0.jar`、`commonmark-0.30.0.jar`、`error_prone_annotations-2.48.0.jar` の計5個。stdlib/coroutinesは同梱していない。IDE同梱ライブラリの利用方針と下限stdlibへの適合は[JetBrains公式資料](https://plugins.jetbrains.com/docs/intellij/using-kotlin.html)を参照。Phase1の旧develop baseline（427クラス/445テスト）の結果を今回のmain候補へ転用していない。

## 次の更新と保管

対象IDEを広げる際は下限SDK・同梱JBR/stdlib・依存の公式互換表を再調査し、descriptor・CI対象・限定warning policyを更新する。非推奨/experimental APIとTerminal optionalの置換要否を判断し、新version/sourceを固定して新RCを一度生成、同一ZIPで必要Verifier/GUI・保存/公開後照合をやり直す。単なるuntil-build拡大や古いpassの転記で対応済みにしない。

正式Releaseと保管RCは上書き・削除せず保持する。branch prereleaseだけは[既存cleanup](../development/plugin-zip-delivery.md#削除済み作業ブランチの掃除219)の識別・所有確認で扱う。公開後の文書修正は新しいPRで行い、Release本文の機械記録やZIPは変更しない。最終のIssue/Project/Milestone・保全資源・監査結果は[#394](https://github.com/shinma06/cursor-in-android-studio/issues/394)が正本。
